# Cover mock templates

HTML scenes used to make the stand-in post covers in `public/images/posts/`.
Open one through the dev server (copy it into `public/` temporarily), set the
browser to 1600x900 and screenshot the viewport.

For real covers from the videos:
- 16:9, at least 1600x900.
- Crop close to the part you annotate. Covers show at about 340px wide on a
  phone, so marker notes need to be large in the frame to stay readable.
- Keep the important part top-left: covers crop from the top-left corner.
- Coral marker: #e2553f, round caps, a little wobble (see `_base.css`).
- Use made-up businesses. Phone numbers from Ofcom's drama range (0113 496 0xxx).
